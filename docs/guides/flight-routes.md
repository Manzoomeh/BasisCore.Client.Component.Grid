# راهنمای ستون‌های گرید

محتوای راهنما برای Template 4 روی هر ستون تعریف می‌شود؛ نیازی به نوشتن selector یا `target` نیست. در دسکتاپ کادر از عنوان ستون تا انتهای سلول همان ستون در اولین ردیف قابل‌مشاهده امتداد دارد؛ نه فقط دور عنوان و نه دور کل ردیف. در موبایل، عنوان و مقدار همان فیلد در اولین کارت با هم برجسته می‌شوند. توضیح مرحله هم، در صورت وجود، نمونهٔ واقعیِ رندرشده از همان ستون در اولین ردیف فعلی را نشان می‌دهد. با فیلتر، مرتب‌سازی و صفحه‌بندی، اولین ردیف فعلی مبناست؛ در جدول بدون داده فقط عنوان ستون برجسته می‌شود.

## شناسه و زبان

### فعال‌سازی دکمه

کلید `guide` در **لایهٔ اول کانفیگ گرید** سوییچ نمایش راهنماست:

```js
guide: true  // استفاده از مراحل تعریف‌شدهٔ ستون‌ها، بدون نیاز به فرادادهٔ سراسری
// یا:
guide: {}    // همان رفتار؛ می‌توان بعداً title، steps یا فراداده را اضافه کرد
// یا:
guide: false // پنهان‌کردن دکمه، حتی اگر ستون‌ها guide فعال داشته باشند
```

با حذف کامل `guide` هم دکمه پنهان است. `true` یا object فقط وقتی دکمه می‌سازد که پس از ترکیب، دست‌کم یک مرحلهٔ معتبر وجود داشته باشد؛ مثلاً اگر همهٔ ستون‌ها `inactive` باشند و مرحلهٔ سراسری هم تعریف نشده باشد، دکمه نمایش داده نمی‌شود. هیچ آموزش عمومی یا محتوای ساختگی خودکار اضافه نمی‌شود.

در حالت `true` عنوان پنجره از برچسب `culture.labels.guide` یا «راهنما» گرفته می‌شود؛ `id` یا `lid` ساختگی تولید نمی‌شود. در object، مشخصات مشترک اختیاری‌اند؛ اما هرکدام که داده شوند باید معتبر باشند: `id`، `lid` و `revision` عدد صحیح مثبت، `schemaVersion` برابر `2` و `title` متن غیرخالی حداکثر ۲۰۰ کاراکتر. رشتهٔ `"true"`، آرایه و `null` معتبر نیستند. برای ثبت فرادادهٔ کامل آموزش در دیتابیس، قرارداد و اعتبارسنجی `isGuideMetadata` همچنان همهٔ مشخصات جدول زیر را الزامی می‌داند.

فایل [flight-routes.json](./flight-routes.json) فرادادهٔ یک راهنمای فارسی است. این فراداده در `options.guide` قرار می‌گیرد؛ متن و فعال‌بودن هر مرحله داخل `guide` همان ستون است:

```js
const options = {
  culture: { template: "template4", /* سایر تنظیمات */ },
  guide: flightRoutesGuide,
  columns: {
    route: {
      title: "مسیر",
      source: row => `${row.route?.start?.city || ""}-${row.route?.end?.city || ""}`,
      guide: {
        status: "active",
        id: "route-row",
        description: "مبدأ و مقصد را کنار هم بخوانید تا مسیر پرواز مشخص شود.",
        optional: true
      }
    },
    airline: {
      title: "ایرلاین",
      source: "airline",
      guide: {
        status: "active",
        id: "airline",
        description: "نام شرکت هواپیماییِ همین مسیر را بررسی کنید."
      }
    },
    code: { title: "کد مسیر", source: "routecode" }
  }
};
```

در راهنمای مسیرها، `options.guide` مشخصات مشترک و قابل ایندکس را نگه می‌دارد؛ `steps` سراسری هم برای اجزای لیست یا صفحه اختیاری است:

| فیلد | کاربرد |
| --- | --- |
| `schemaVersion` | نسخهٔ قرارداد؛ فعلاً `2`. |
| `id` | شناسهٔ عددی مثبت و پایدار راهنما. برای ترجمه‌ها ثابت می‌ماند. |
| `lid` | شناسهٔ عددی مثبت زبان محتوا. |
| `revision` | با تغییر محتوای منتشرشده افزایش می‌یابد. |
| `title` | نام دسترس‌پذیر پنجرهٔ راهنما. |

اگر هر ترجمه رکورد جداگانه‌ای در دیتابیس است، روی `(id, lid)` ایندکس مرکب یکتا بگذارید.

## تنظیم راهنمای ستون

| فیلد | کاربرد |
| --- | --- |
| `status` | `active` مرحله را وارد راهنما می‌کند؛ `inactive` آن را کنار می‌گذارد. |
| `id` | شناسهٔ رشته‌ای یکتای مرحله در همان راهنما، مثل `route-row`. |
| `description` | توضیح ثابت و متناسب با معنای ستون؛ متن ساده است، نه HTML. |
| `optional` | اگر `true` باشد و عنوان ستون در نمای فعلی نباشد، مرحله حذف می‌شود؛ در غیر این صورت پیام در دسترس نبودن هدف نمایش داده می‌شود. |
| `priority` | عدد صحیح نامنفی؛ عدد کوچک‌تر زودتر اجرا می‌شود. مقدار پیش‌فرض `1000` است. |
| `steps` | چند مرحله برای همان ستون؛ هر مرحله `id` و `description` دارد. `target` و `title` اختیاری‌اند و در صورت حذف از همان ستون گرفته می‌شوند. برای اکشن منو، `target` معنایی اکشن را مشخص کنید. |

مراحل ستون‌ها و تمام `options.guide.steps` ترکیب می‌شوند و `priority` ترتیب نهایی را مشخص می‌کند. هر مرحلهٔ داخلی می‌تواند اولویت والد را بازنویسی کند؛ در اولویت مساوی ترتیب ستون/آرایه حفظ می‌شود و مراحل سراسری بعد از مراحل ستون‌ها می‌آیند. اگر ستون فقط `steps` داشته باشد، معرفی جداگانه‌ای اضافه نمی‌شود؛ با `description`، معرفی ستون هم یک مرحله است. عنوان مرحلهٔ ستون از `column.title` می‌آید و target به‌صورت امن از خود کامپوننت resolve می‌شود. نام ستون یا متن JSON به selector یا JavaScript تبدیل نمی‌شود. نمونهٔ کامل ستون عملیات و قواعد ارث‌بری در [راهنمای عملیات](actions.md) آمده است.

نمونهٔ ردیف اول در زمان شروع راهنما از محتوای رندرشدهٔ همان ستون خوانده می‌شود؛ بنابراین `cellMaker` نیز نمونهٔ قابل‌مشاهدهٔ خود را ارائه می‌کند. متن نمونه به‌صورت متن ساده نمایش داده می‌شود. در صورت نبود ردیف یا مقدار، توضیح ثابت بدون نمونه باقی می‌ماند.

دکمهٔ راهنما فقط با `guide: true` یا object معتبر در لایهٔ اول و دست‌کم یک مرحلهٔ معتبر و فعال نمایش داده می‌شود. راهنمای ستون به‌تنهایی آن را فعال نمی‌کند. راهنما داده، فیلتر، انتخاب یا عملیات گرید را تغییر نمی‌دهد.

## هدف‌های خارج از ستون

برای هدفی مثل دکمهٔ افزودن صفحه، `steps` سراسری و `guideTargets` را نگه دارید. این مراحل حتی همراه راهنمای ستون اجرا می‌شوند؛ مثلاً `priority: 0` آن را قبل از ستون‌های بدون اولویت قرار می‌دهد.

```js
guideTargets: {
  "page.create": () => document.querySelector("#create-flight")
}
// این مرحله را به options.guide.steps اضافه کنید:
// {id: "create-flight", target: "page.create", priority: 0,
//  title: "افزودن مسیر", description: "از این بخش مسیر جدید ثبت کنید."}
```

در `steps` قدیمی، `target` باید نام منطقیِ ثبت‌شده باشد، مثل `page.create`؛ selector خام پذیرفته نمی‌شود. ترجیحاً راهنمای ستون‌ها را برای محتوای داخل گرید به‌کار ببرید و target بیرونی را فقط وقتی لازم است اضافه کنید.

## سازگاری

این قابلیت به Template 4 محدود است و Templateهای 1 تا 3 تغییر نمی‌کنند. راهنمای تک‌توضیحی قبلی و `guide.steps` سراسری همچنان کار می‌کنند. تغییر عمدی این نسخه: مراحل سراسری غیرِاکشن دیگر در حضور راهنمای ستون حذف نمی‌شوند. مرحله‌ای را هم‌زمان در ستون و سراسری تکرار نکنید؛ شناسه‌های مراحل نهایی باید یکتا و تعدادشان حداکثر ۵۰ باشد. برای تغییر محتوای منتشرشده `revision` را افزایش دهید.
