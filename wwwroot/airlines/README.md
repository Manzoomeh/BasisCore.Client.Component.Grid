# Airline Assets

The PNG logos are locally served copies of the corresponding airline marks from
Google Flights' airline image CDN: `https://www.gstatic.com/flights/airline_logos/70px/{IATA}.png`.
`IA.png` uses `https://images.kiwi.com/airlines/64/IA.png` because the Google
endpoint returns a generic placeholder for this airline.

Fetched on 2026-11-04 for the flight-routes demonstration. Airline names and logos
belong to their respective owners. These are source assets, not generated images.
